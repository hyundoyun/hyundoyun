# 유튜브 연결하기 (레퍼런스 영상 받기)

유튜브는 클라우드 컴퓨터에서 영상을 받으려 하면 "로봇 아니냐"며 막습니다.
**내 유튜브 로그인 정보(쿠키)** 를 한 번 넣어두면, 앞으로 "레퍼런스 분석해줘"를 할 때마다 영상을 통째로 받아
소리·컷 빠르기까지 잴 수 있습니다. 넣지 않으면 미리보기 사진만 보고 분석합니다.

## ⚠️ 먼저 알아두기
- 쿠키는 **그 구글 계정에 로그인된 상태** 그 자체입니다. 남에게 보내거나 채팅창에 붙여넣지 마세요.
- 그래서 **영상 보기용 부계정**(새 구글 계정)으로 하는 걸 권합니다. 유튜브가 드물게 그 계정을 잠시 막을 수도 있습니다.
- 이 저장소에는 절대 올라가지 않습니다(환경 설정에만 저장).

## 1. 쿠키 파일 만들기 (내 컴퓨터, 크롬)
1. 크롬 웹스토어에서 **"Get cookies.txt LOCALLY"** 확장 프로그램을 설치합니다.
2. 크롬에서 **시크릿 창**을 열고 youtube.com 에 (부)계정으로 로그인합니다.
3. 그 시크릿 창 그대로, 확장 프로그램 아이콘 → (시크릿 창에서도 켜지게 허용) → **Export** → `www.youtube.com_cookies.txt` 저장.
4. **시크릿 창을 바로 닫습니다.** (창을 계속 쓰면 유튜브가 쿠키를 바꿔버려서 받은 파일이 금방 못 쓰게 됩니다.)

## 2. 환경 설정에 넣기
1. 받은 txt 파일을 메모장으로 열어 **전체 복사**합니다.
2. Claude 코드 화면 위쪽의 클라우드 환경 이름 → **Edit** → 환경 변수(Environment variables)에
   이름 `YOUTUBE_COOKIES`, 값에 방금 복사한 내용을 붙여넣고 저장합니다.
   (줄바꿈이 사라져 한 줄로 붙어도 괜찮습니다. 프로그램이 알아서 다시 나눕니다.)
3. **새 대화**를 열어 "레퍼런스 분석해줘"라고 말하면 됩니다.

## 3. 잘 됐는지 확인
`python3 -m editor check` → `== 유튜브 레퍼런스 받기 ==` 아래가
- ✅ 영상 받기 가능 (로그인 쿠키 사용) → 연결 완료
- ❌ 쿠키가 있지만 막힘 → 쿠키가 만료됨. 1번부터 다시(보통 몇 주~몇 달에 한 번)
