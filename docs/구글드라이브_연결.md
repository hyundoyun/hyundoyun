# 구글 드라이브 연결 방법

“구글 드라이브에 영상 올렸어, 편집해줘” 한마디로 동작하게 하려면 **한 번만** 아래를 해 두면 됩니다.

## 방법 A. 자동 (추천) — 서비스 계정 키 (약 10분, 한 번만)

이 방식은 현재 클라우드 환경의 인터넷 설정 그대로도 동작합니다(googleapis.com 은 열려 있음).

1. https://console.cloud.google.com 접속 → 위쪽 프로젝트 선택 → **새 프로젝트** (이름 아무거나, 예: `video-editor`).
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Google Drive API` 검색 → **사용**.
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정** → 이름 입력 → 완료.
4. 만든 서비스 계정 클릭 → **키** 탭 → **키 추가 → 새 키 만들기 → JSON** → 파일이 내려받아짐.
   서비스 계정 이메일(예: `editor@video-editor.iam.gserviceaccount.com`)을 복사해 둡니다.
5. 내 구글 드라이브에 폴더 두 개 만들기: **`편집할영상`**, **`편집완료`**.
   두 폴더 모두 **공유** → 4번의 서비스 계정 이메일을 **편집자**로 추가.
6. Claude 클라우드 환경 설정에 키 넣기: 세션 제목줄의 **클라우드 환경 메뉴 → Edit** →
   환경 변수에 이름 **`GDRIVE_SERVICE_ACCOUNT_JSON`**, 값은 4번 JSON 파일의 **내용 전체**를 붙여넣기.
   (키는 채팅창에 붙여넣지 마세요. 환경 설정에만 넣으세요.)
7. 새 세션을 시작하면 적용됩니다.

이후: 영상을 `편집할영상` 폴더에 올리고 “구글 드라이브에 영상 올렸어, 편집해줘” → 가장 최근 영상을 받아 편집하고,
완성본은 `편집완료` 폴더에 올라갑니다.

## 방법 B. 공유 링크 (설정 없이 바로)

드라이브에서 영상 → **공유 → 링크가 있는 모든 사용자(뷰어)** → 링크 복사 → “이 링크 편집해줘: <링크>”.
단, 이 방식은 클라우드 환경 인터넷 설정에서 `drive.google.com`, `drive.usercontent.google.com` 접속이 허용돼야 합니다
(클라우드 환경 메뉴 → Edit → Network access 를 더 넓은 단계로, 또는 Custom 에 두 주소 추가).

## Claude 의 구글 드라이브 커넥터

https://claude.ai/customize/connectors 에서 Google Drive 를 연결하면 Claude 가 드라이브의 파일 목록·문서를 볼 수 있습니다.
연결 후에는 새 세션을 시작해야 적용됩니다. 다만 커넥터는 큰 영상 파일을 내려받는 용도로는 적합하지 않아,
실제 영상 받기는 방법 A 또는 B 를 씁니다.
