# 편집 규칙집

> 이 문서는 사람이 읽는 설명서이고, 프로그램이 실제로 읽는 값은 `config/rules.json` 에 있습니다.
> 두 곳은 항상 함께 고칩니다. 아쉬운 점을 말하면 아래 **피드백 반영 기록**에 쌓이고 다음 편집부터 자동으로 적용됩니다.

## 0. 현재 상태

- **레퍼런스 분석: 아직 안 함.** 처음 요청에 유튜브 링크가 빠져 있었고(“여기에 유튜브 링크 3~4개” 자리만 있었음),
  이 클라우드 환경에서는 유튜브 접속이 막혀 있습니다.
  지금 규칙은 한국 정보·토크형 유튜브에서 흔히 쓰는 편집 방식으로 채운 **기본값**입니다.
- 링크를 주고 환경에서 `www.youtube.com` 접속을 허용하면 `python -m editor analyze 링크1 링크2 …` 한 번으로
  아래 **레퍼런스 측정값**이 채워지고 `rules.json` 의 숫자들이 측정값으로 자동 교체됩니다.
  그다음 Claude 가 장면 썸네일(`refs/<영상ID>/contact_*.jpg`)을 직접 보고 글꼴 느낌·인트로 구성처럼
  숫자로 안 잡히는 부분을 이 문서에 보충합니다.

## 1. 편집 순서 (반드시 이 순서)

| 단계 | 하는 일 | 결과물 |
|---|---|---|
| ① 받아쓰기 | 원본 음성을 단어 하나하나 시간과 함께 받아쓴다 | `work/<영상>/transcript.json` |
| ② 교정 대본 | 더듬은 곳, 같은 말 반복, 다시 말한 곳, 긴 멈춤을 **빼기만** 한다. 말 내용·말투는 그대로 | `교정대본.md`, `script.json` |
| ③ 컷 편집 | 교정 대본에 남은 말만 이어 붙인다 | `cut.mp4` |
| ④ 자막·강조·소리 | 자막, 강조 자막, 효과음, 배경음을 규칙대로 넣는다 | `final.ass`, `final_mix.wav` |
| ⑤ 자료화면 | 말한 내용에 맞는 공식 사이트·기사 제목 화면 + 작은 출처 | `broll/` |
| ⑥ 저장 | mp4 로 완성 | `output/<영상>_편집본.mp4` |
| 검수 | 자막 오타, 소리 끊김, 화면 멈춤, 개인정보 → 고치고 다시 저장 → 보고 | `output/<영상>_편집본_검수보고서.md` |

## 2. 장면 단위 규칙

### 2-1. 컷 (말 기준)
- 남기는 단위는 **단어**. 단어 앞 0.06초, 뒤 0.10초 여유(`cut.pad_*`).
- 말 사이 멈춤이 0.45초 이상이면 잘라내고, 이음새는 자연스러운 0.12~0.16초 간격만 남긴다(`script_cleanup.long_pause_sec`).
- 이음새마다 12ms 소리 페이드 → ‘틱’ 소리 없음.
- 군말 목록(어, 음, 으…)은 단어째 삭제. 앞부분만 말하다 만 더듬음(“괜 괜찮은”)은 앞 조각 삭제.
- 같은 말 반복(“오늘은 오늘은”)은 **앞의 것**을 지운다(뒤에 다시 한 말이 보통 더 또렷함).
  단 “정말 정말”, “진짜 진짜” 같은 일부러 하는 반복은 남긴다.
- 문장을 말하다 멈추고 같은 첫마디로 다시 시작하면 앞의 미완성 부분을 지운다.

### 2-2. 화면 확대(줌)
- **점프컷 줌**: 컷이 바뀔 때마다 1.00 ↔ 1.12 배를 번갈아 → 튀는 느낌 제거.
- 한 화면이 7초 넘게 이어지면 단어 사이에서 줌을 바꿔 리듬을 준다(`zoom.max_static_sec`, 레퍼런스 컷 간격으로 자동 조정).
- **펀치 줌**: 강조 단어가 나오는 순간 1.22배로 ‘확’ 당겨 1.2초 유지.
- 화면 중심은 위쪽 42% 지점(얼굴이 잘리지 않게).

### 2-3. 자막
| 항목 | 값 |
|---|---|
| 글꼴 | Pretendard ExtraBold |
| 크기 | 68px (1080p 기준) |
| 색 | 흰색 #FFFFFF, 검정 테두리 5px + 그림자 2px |
| 위치 | 화면 아래 가운데, 바닥에서 90px |
| 한 줄 길이 | 최대 18자, 한 줄만 |
| 끊는 곳 | 문장 끝, 숨 쉬는 곳(0.7초 이상), 18자 넘을 때, ‘~요/~다/~고/~는데’ 뒤 |
| 문장부호 | 마침표·쉼표는 찍지 않음, 물음표·느낌표는 유지 |
| 강조 단어 | 같은 줄 안에서 노란색 #FFE14D |

### 2-4. 강조 자막
- 글꼴 Black Han Sans, 120px, 화면 위쪽 22% 지점, 두꺼운 검정 테두리 8px.
- 색은 노랑 → 빨강 → 하늘 순서로 돌아가며.
- **뜨는 순간**: 숫자(3배, 50%, 1위…), 핵심어(진짜·핵심·중요·무조건·꿀팁·결론…), 느낌표 문장. 그 단어를 말하는 바로 그 순간.
- 등장: 40% → 115% → 100% 로 ‘팝’(0.16초), 1.4초 유지 후 사라짐.
- 최소 4초 간격, 1분에 최대 8개.

### 2-5. 효과음
| 순간 | 소리 |
|---|---|
| 강조 자막이 뜰 때 | 팝(pop) |
| 자료화면이 들어올 때 | 휙(whoosh) |
| 인트로 제목 카드 | 휙(whoosh) |
| 아웃트로 | 딩(ding) |
- 크기 -8dB, 화면보다 0.03초 먼저.
- `assets/sfx/pop.wav` 처럼 같은 이름으로 내 효과음을 넣으면 그걸 쓴다.

### 2-6. 배경음
- 영상 전체에 깔고 크기 -24dB, **말할 때는 8dB 더 작아짐**(자동 덕킹).
- 시작 1초 페이드인, 끝 2.5초 페이드아웃.
- `assets/bgm/` 에 내 음악을 넣으면 그걸 쓰고, 없으면 저작권 없는 로파이 음악을 직접 합성.
- 최종 음량은 유튜브 기준 -14 LUFS 로 맞춤.

### 2-7. 자료화면
- 말에서 회사·서비스·제품·뉴스·통계가 나오면, 그 말을 하는 순간 **공식 사이트 화면** 또는 **기사 제목**을 띄운다.
- 화면 오른쪽 위 카드(화면 너비 56%, 둥근 모서리, 그림자), 3.2초, 0.2초 페이드. 최소 6초 간격.
- 카드 바로 아래 오른쪽에 **작은 출처**(26px, 반투명 흰색): `출처: 사이트/언론사 이름`.
- 실제 화면 캡처가 가능하면 캡처, 막혀 있으면 기사 제목·사이트 주소를 담은 브라우저 모양 카드로 만든다.
- 기사 제목은 원문 그대로 쓰고 바꾸지 않는다.

### 2-8. 인트로
1. **훅**: 영상에서 가장 인상적인 한 문장(첫 강조 문장)을 맨 앞에 최대 6초 미리 보여준다. 문장 중간에서 끊지 않는다.
2. **제목 카드**: 검은 배경 + 큰 제목(Black Han Sans 110px, 마지막 줄 노란색) 1.8초, 휙 효과음.
3. 그 다음 본편.

### 2-9. 아웃트로
- 마지막 말이 끝나면 “구독 · 좋아요 · 알림 설정 / 다음 영상에서 만나요!” 카드 4초, 딩 효과음, 배경음 페이드아웃.

### 2-10. 검수 기준
| 항목 | 확인 방법 | 자동 수정 |
|---|---|---|
| 자막 오타 | 맞춤법 사전 + 인식이 불확실한 줄 목록 → Claude 가 문맥으로 확인 | 사전 교체, 인식 오류는 들린 말 그대로 표기 수정 |
| 소리 끊김 | 본편 속 0.9초 이상 무음, 자막은 있는데 소리 없는 단어, 이음새 튐, 영상·소리 길이 차이 | 해당 단어 컷 후 재편집 |
| 화면 멈춤 | 1.5초 이상 같은 화면(제목·아웃트로 카드 제외) | 그 구간에 천천히 움직이는 줌 |
| 개인정보 | 0.5초마다 화면 글자 인식: 이메일, 휴대폰·전화번호, 주민번호, 카드·계좌번호, ‘비밀번호/주소/계좌’ 등 | 원본 좌표에 모자이크 → 완성본에서 다시 인식해 안 보이는지 확인 |
