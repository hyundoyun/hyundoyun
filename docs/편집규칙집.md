# 편집 규칙집

> 이 문서는 사람이 읽는 설명서이고, 프로그램이 실제로 읽는 값은 `config/rules.json` 에 있습니다.
> 두 곳은 항상 함께 고칩니다. 아쉬운 점을 말하면 아래 **피드백 반영 기록**에 쌓이고 다음 편집부터 자동으로 적용됩니다.

## 0. 현재 상태

- **레퍼런스 분석: 분석 완료(2026-10-15, 영상 5개).** 단, 유튜브가 이 클라우드 서버의 영상 내려받기를 ‘로봇 확인’으로 막아서
  영상 전체가 아니라 **유튜브 미리보기 그림**(영상마다 약 5~10초 간격의 작은 장면 사진 100~170장)을 눈으로 보고 정했습니다.
  그래서 화면 모양(자막·강조 자막·자료화면·인트로·아웃트로)은 레퍼런스대로 바뀌었고,
  **소리(효과음·배경음)와 정확한 컷 간격은 측정하지 못해 기본값 그대로**입니다.
- 영상까지 받아 숫자로 재려면: 유튜브에 로그인된 브라우저에서 쿠키 파일을 내보내 `config/youtube_cookies.txt` 로 넣고
  `python3 -m editor analyze` 를 다시 실행하면 됩니다(이 파일은 저장소에 올라가지 않음). 그러면 3장 측정값이 채워집니다.

## 1. 편집 순서 (반드시 이 순서)

| 단계 | 하는 일 | 결과물 |
|---|---|---|
| ① 받아쓰기 | 원본 음성을 단어 하나하나 시간과 함께 받아쓴다 | `work/<영상>/transcript.json` |
| ② 교정 대본 | 더듬은 곳, 같은 말 반복, 다시 말한 곳, 긴 멈춤을 **빼기만** 한다. 말 내용·말투는 그대로 | `교정대본.md`, `script.json` |
| ③ 컷 편집 | 교정 대본에 남은 말만 이어 붙인다 | `cut.mp4` |
| ④ 자막·강조·소리 | 자막, 강조 자막, 효과음, 배경음을 규칙대로 넣는다 | `final.ass`, `final_mix.wav` |
| ⑤ 자료화면 | 말한 내용에 맞는 공식 사이트·기사 제목 화면 + 작은 출처 | `broll/` |
| ⑥ 저장 | mp4 로 완성 | `output/<영상>_편집본.mp4` |
| 검수 | 자막 오타, 소리 끊김, 화면 멈춤, 개인정보 → 고치고 다시 저장 → 보고 | `output/<영상>_편집본_검수보고서.md` |

## 2. 장면 단위 규칙

### 2-1. 컷 (말 기준)
- 남기는 단위는 **단어**. 단어 앞 0.06초, 뒤 0.10초 여유(`cut.pad_*`).
- 말 사이 멈춤이 0.45초 이상이면 잘라내고, 이음새는 자연스러운 0.12~0.16초 간격만 남긴다(`script_cleanup.long_pause_sec`).
- 이음새마다 12ms 소리 페이드 → ‘틱’ 소리 없음.
- 군말 목록(어, 음, 으…)은 단어째 삭제. 앞부분만 말하다 만 더듬음(“괜 괜찮은”)은 앞 조각 삭제.
- 같은 말 반복(“오늘은 오늘은”)은 **앞의 것**을 지운다(뒤에 다시 한 말이 보통 더 또렷함).
  단 “정말 정말”, “진짜 진짜” 같은 일부러 하는 반복은 남긴다.
- 문장을 말하다 멈추고 같은 첫마디로 다시 시작하면 앞의 미완성 부분을 지운다.

### 2-2. 화면 확대(줌)
- **점프컷 줌**: 컷이 바뀔 때마다 1.00 ↔ 1.15 배를 번갈아 → 튀는 느낌 제거.
  레퍼런스는 넓은 화면(두 사람/상반신)과 가까운 화면(얼굴 위주)을 자주 번갈아 씀. 카메라 1대 영상은 이 확대로 비슷하게 만든다.
- 한 화면이 7초 넘게 이어지면 단어 사이에서 줌을 바꿔 리듬을 준다(`zoom.max_static_sec`, 레퍼런스 컷 간격으로 자동 조정).
- **펀치 줌**: 강조 단어가 나오는 순간 1.22배로 ‘확’ 당겨 1.2초 유지.
- 화면 중심은 위쪽 42% 지점(얼굴이 잘리지 않게).

### 2-3. 자막
| 항목 | 값 |
|---|---|
| 글꼴 | Pretendard ExtraBold (레퍼런스: 깔끔한 굵은 고딕) |
| 크기 | 58px (1080p 기준) — 레퍼런스는 화면 높이의 약 5% 로 크지 않음 |
| 모양 | **반투명 검은 상자(#000000A6, 여백 14px) 안에 흰 글씨** — 레퍼런스 5개 중 4개가 이 방식 |
| 위치 | 화면 아래 가운데, 바닥에서 70px |
| 한 줄 길이 | 최대 22자, 한 줄만 |
| 끊는 곳 | 문장 끝, 숨 쉬는 곳(0.7초 이상), 18자 넘을 때, ‘~요/~다/~고/~는데’ 뒤 |
| 문장부호 | 마침표·쉼표는 찍지 않음, 물음표·느낌표는 유지 |
| 강조 단어 | 같은 줄 안에서 초록색 #7CFF4F (레퍼런스 채널의 대표색) |
| 따옴표 | 레퍼런스는 인용·이름에 ‘작은따옴표’를 자주 씀(말한 그대로일 때만) |
- 참고: 5개 중 1개(임효성 채널)는 상자 없이 작은 흰 글씨만 씀.

### 2-4. 강조 자막
- 레퍼런스: 화면 **아래쪽**(자막 바로 위, 가슴 높이)에 **아주 큰 굵은 글씨**. 위쪽에 띄우지 않는다.
  예) “노출 1/5 = 문의 1/5”, “요즘 리더의 판단력 = AI 활용 능력”, “다 무시하세요”.
- 글꼴 Black Han Sans, 124px, 화면 70% 높이, 두꺼운 검정 테두리 9px.
- 색은 흰색 → 초록 → 주황빨강 → 노랑 순서로 돌아가며(레퍼런스는 문장은 흰색, 핵심 단어만 초록/주황/노랑).
- 레퍼런스에는 이 위에 작은 초록 글씨 꼬리표([AI 초심자라면], [블로그 노출 X → 문의 1/6 토막])가 붙기도 함 → **아직 자동 아님**(2-11).
- **뜨는 순간**: 숫자(3배, 50%, 1위…), 핵심어(진짜·핵심·중요·무조건·꿀팁·결론…), 느낌표 문장. 그 단어를 말하는 바로 그 순간.
- 등장: 40% → 115% → 100% 로 ‘팝’(0.16초), 1.4초 유지 후 사라짐.
- 최소 4초 간격, 1분에 최대 8개.

### 2-5. 효과음
| 순간 | 소리 |
|---|---|
| 강조 자막이 뜰 때 | 팝(pop) |
| 자료화면이 들어올 때 | 휙(whoosh) |
| 인트로 제목 카드 | 휙(whoosh) |
| 아웃트로 | 딩(ding) |
- 크기 -8dB, 화면보다 0.03초 먼저.
- `assets/sfx/pop.wav` 처럼 같은 이름으로 내 효과음을 넣으면 그걸 쓴다.

### 2-6. 배경음
- 영상 전체에 깔고 크기 -24dB, **말할 때는 8dB 더 작아짐**(자동 덕킹).
- 시작 1초 페이드인, 끝 2.5초 페이드아웃.
- `assets/bgm/` 에 내 음악을 넣으면 그걸 쓰고, 없으면 저작권 없는 로파이 음악을 직접 합성.
- 최종 음량은 유튜브 기준 -14 LUFS 로 맞춤.

### 2-7. 자료화면
- 말에서 회사·서비스·제품·뉴스·통계가 나오면, 그 말을 하는 순간 **공식 사이트 화면** 또는 **기사 제목**을 띄운다.
- 레퍼런스: 자료화면이 **아주 많음**(장면 사진의 대략 절반이 자료화면). 블로그·검색 결과·인스타그램·기사·책 표지 등
  화면 캡처를 **전체 화면**으로 크게 보여주고, **오른쪽 아래에 말하는 사람을 둥근 작은 창**으로 계속 보여준다.
- 그래서: 전체 화면(`broll.mode: full`) + 얼굴 작은 창(화면 너비 22%, 둥근 모서리, 오른쪽 아래), 4.5초, 최소 4초 간격.
  (`mode: pip` 로 바꾸면 예전처럼 오른쪽 위 카드)
- 전체 화면일 때 작은 출처는 얼굴 창에 가리지 않게 **왼쪽 아래**에 붙인다.
- 카드 바로 아래 오른쪽에 **작은 출처**(26px, 반투명 흰색): `출처: 사이트/언론사 이름`.
- 실제 화면 캡처가 가능하면 캡처, 막혀 있으면 기사 제목·사이트 주소를 담은 브라우저 모양 카드로 만든다.
- 기사 제목은 원문 그대로 쓰고 바꾸지 않는다.
- 레퍼런스는 캡처 속 중요한 곳에 **빨간/초록 네모 테두리**를 치고 나머지를 어둡게 하기도 함 → 아직 자동 아님(2-11).
- 사진 자료(사람·풍경)는 파란 찢어진 종이 테두리 안에 넣기도 함 → 아직 자동 아님.

### 2-8. 인트로
레퍼런스: 첫 장면부터 **질문·반응·핵심 장면**으로 바로 시작하고(“이번에 <오디세이> 영화 보셨어요?”, “와…”),
큰 강조 글씨로 주제를 던진 뒤, **검은 화면에 채널 로고**가 잠깐 나오고 본편으로 넘어간다.
1. **훅**: 영상에서 가장 인상적인 한 문장(첫 강조 문장)을 맨 앞에 최대 8초 미리 보여준다. 문장 중간에서 끊지 않는다.
2. **제목 카드**: 검은 배경 + 큰 제목(Black Han Sans 110px, 마지막 줄 노란색) 1.5초, 휙 효과음.
3. 그 다음 본편.

### 2-9. 아웃트로
- 레퍼런스: 따로 구독 카드가 없다. 마지막 “감사합니다”를 말하는 동안 **화면이 1.5초에 걸쳐 어두워지며** 끝난다
  (자막 ‘감사합니다’는 검은 화면 위에 남음). 1개 영상은 끝에 채널 이름 + 구독 버튼 띠가 아래에 잠깐 나옴.
- 그래서: `outro.style: fade` (카드 없음, 1.5초 어두워짐, 배경음 페이드아웃). `style: card` 로 바꾸면 예전 구독 카드 4초 + 딩.

### 2-10a. 채널 로고
- 레퍼런스는 **왼쪽 위에 채널 로고가 항상 작게** 떠 있다. `assets/logo.png` 를 넣으면 자동으로 붙는다(폭 220px, 없으면 건너뜀).

### 2-10. 검수 기준
| 항목 | 확인 방법 | 자동 수정 |
|---|---|---|
| 자막 오타 | 맞춤법 사전 + 인식이 불확실한 줄 목록 → Claude 가 문맥으로 확인 | 사전 교체, 인식 오류는 들린 말 그대로 표기 수정 |
| 소리 끊김 | 본편 속 0.9초 이상 무음, 자막은 있는데 소리 없는 단어, 이음새 튐, 영상·소리 길이 차이 | 해당 단어 컷 후 재편집 |
| 화면 멈춤 | 1.5초 이상 같은 화면(제목·아웃트로 카드 제외) | 그 구간에 천천히 움직이는 줌 |
| 개인정보 | 0.5초마다 화면 글자 인식: 이메일, 휴대폰·전화번호, 주민번호, 카드·계좌번호, ‘비밀번호/주소/계좌’ 등 | 원본 좌표에 모자이크 → 완성본에서 다시 인식해 안 보이는지 확인 |

### 2-11. 레퍼런스에 있지만 아직 자동으로 안 하는 것
| 모양 | 설명 |
|---|---|
| 초록 꼬리표 | 자막 위 작은 초록 글씨 [요약 한 줄] — 말에 없는 말을 덧붙이는 것이라 지금은 넣지 않음 |
| 네모 강조 | 캡처 속 중요한 곳 빨간/초록 네모 + 나머지 어둡게 |
| 사진 테두리 | 사람·풍경 사진에 파란 찢어진 종이 테두리 |
| 웃음 장면 | 흑백 처리 + 얼굴 동그라미 + (ㅋㅋㅋㅋ) 같은 반응 글씨 |
| 소리 | 효과음·배경음은 영상을 못 받아 확인 못 함 → 기본값 유지 |
